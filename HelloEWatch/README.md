# WatchEWord

HelloEWordでエクスポートした単語をiPhoneで取り込み、Apple Watchで単語と意味を閲覧するアプリです。

iPhone・Apple Watchのアプリ表示名はどちらも **WatchEWord** です。プロジェクト名・Scheme名は従来のHelloEWatch／EWatch Watch Appを使用します。Bundle IDは維持しており、既存アプリの更新としてインストールする設定です。

## 開発環境と実機へのインストール

プロジェクトの最低対応OSはiOS 18.1／watchOS 11.1です。対象OSと実機をサポートするXcodeで `HelloEWatch.xcodeproj` を開いてください。

1. iPhoneとApple Watchをペアリングし、両方のデベロッパモードを有効にします。
2. iPhoneをMacに接続し、必要に応じてMacへの信頼を許可します。実機をロック解除し、Mac・iPhone・Watchが通信できるネットワークに接続します。
3. Xcodeで両ターゲットの「Signing & Capabilities」を開き、自分のTeamと署名設定を確認します。
4. Schemeを **HelloEWatch**、実行先を自分のiPhoneにしてRun（⌘R）します。
5. Schemeを **EWatch Watch App**、実行先を自分のApple WatchにしてRun（⌘R）します。

Watch側だけを変更した場合も、WatchのSchemeと実機を選んで再度Runして更新します。今回の通信形式に対応するため、初回はiPhone・Watchの両方を更新してください。

「Waiting to reconnect」が表示される場合は、Xcodeのデバイス管理画面（Devices and Simulators／Device Hub）で接続状態と端末側の接続許可を確認します。これは実機への接続準備に関する表示で、ソースのビルドエラーとは分けて確認してください。

## 取り込み

1. iPhoneで「HelloEWordのデータをインポート」を選びます。
2. JSONまたはCSVを選び、ファイルを開きます。
3. 全件の検証後、取り込む本を選択します。
4. 保存方法を確認し、「取り込む」を押します。初期選択は「追記」です。既存データをクリアして取り込む場合は「全データを置き換え」を選び、続く確認画面で実行します。

追記は既存の単語を残して追加し、既存データの削除・重複排除は行いません。同じデータの再取り込みは重複します。置き換えは選択していない本も含む既存の全単語を削除し、選択した本だけを保存します。置き換えには追加の確認があります。

ファイル選択・内容確認のキャンセルと入力検証エラーではDBを変更しません。保存と保存結果の読み出しはトランザクション内で実行し、失敗時はロールバックします。取消自体に失敗した場合はそのエラーを表示します。入力ファイルのIDは再利用せず、端末側で採番します。

### 対応形式

- HelloEWordの全項目JSON（配列）
- 従来の8項目JSON／出題用JSON（book, stage, page, numb, word, mean, eibun, wabun）
- UTF-8の16列CSV。BOM、CRLF、引用符内のカンマ・改行、二重引用符のエスケープに対応

```csv
ID,連番,単語,品詞,意味,語釈,類似語,反意語,関連語,英文,和文,備考,本,章,頁,通番
```

CSVの連番・頁・通番は整数、章は文字列です。従来JSONの省略項目は空文字、連番は0として取り込みます。単語の空欄、NUL文字、不正な列数・数値、空データは取り込みません。

## 検索とWatch

iPhoneの検索欄には「本」「章」「頁」を表示します。「対象」と「検索」ボタンはなく、選択を変更すると自動で検索結果を更新します。各選択肢の先頭に「すべて」があり、初期状態は3項目とも「すべて」です。

- 本を選ぶと、章・頁を「すべて」に戻し、選択した本の章候補を昇順で表示して、その本の単語を検索します。
- 章を選ぶと、頁を「すべて」に戻し、選択した本・章の頁候補を数値の昇順で表示して、その本・章の単語を検索します。
- 頁を選ぶと、本・章・頁の条件を組み合わせて検索します。
- 本が「すべて」の場合は全本から章候補を作ります。章が「すべて」の場合は選択した本の全章から頁候補を作ります。

章は文字列として保持し、数字を含む名前は自然順（例：1、2、10）で並べます。空の本名・章名や頁0も選択でき、「すべて」と区別します。取り込み成功後は3項目を「すべて」に戻します。

「検索結果をWatchに送る」で先頭の単語を送ります。検索変更時にも最新の表示を同期します。

Watchでは左スワイプで次の単語、右スワイプで前の単語へ移動します。画面下の前後移動用矢印は表示しません。単語のタップで意味を表示・非表示にします。長い意味は縦スクロールできます。

通常時は同期ボタンを表示しません。通信失敗・10秒の応答タイムアウト・受信データ異常・iPhoneからの処理エラーなどを検出すると、小さい文字とカプセル形の「再同期」ボタンを表示します。押すとiPhoneの最新表示を取得します。アプリのアップデートを行うボタンではありません。

未接続・通信中は「再同期」を無効化します。接続復帰だけでは失敗状態を解除せず、正常なデータを受信したらボタンを非表示にします。古いデータを無視した場合は失敗状態を解除しません。正常に検索結果0件を受信した場合はデータなしの案内を表示します。

起動・画面復帰・再接続時の自動同期は維持します。Watchがまだ受信していないiPhoneの変更を、Watch単独で検出する処理や、表示ずれを調べるための定期通信は追加していません。

番号と単語は受信結果に基づいて一緒に更新します。通信中の連打を抑止し、応答が10秒間ない場合は再試行を案内します。遅延・重複した移動要求や古い検索への要求は、新しい状態を巻き戻さないよう処理します。

未接続でも直前に受信した1件はWatch内に保持します。未接続時の単語移動には対応していません。起動・再接続時に最新状態を取得します。通信形式を変更したため、iPhoneとWatchの両方を今回のソースで更新してください。

既存DBは従来の `Documents/eword_watch_sqlite3`、テーブル `watchEword` をそのまま使用します。初回起動では空テーブルを作成し、取り込みを案内します。

## WatchEWordについて

タイトル「WatchEWord」と同じ行の右端にある歯車を押し、「About」を選ぶと「WatchEWordについて」を表示します。アプリアイコンとVersion・Revisionを掲載し、「閉じる」で元の画面に戻ります。

Versionはアプリの `CFBundleShortVersionString`、Revisionは `CFBundleVersion`（ビルド番号）から取得します。現在のプロジェクト設定はVersion 1.0／Revision 1です。検索変更を識別する通信上のrevisionとは別の値です。

## ソース構成

| ファイル | 役割 |
| --- | --- |
| `HelloEWatch/ContentView.swift` | 検索・取り込み・置き換え確認画面 |
| `HelloEWatch/AboutView.swift` | 「WatchEWordについて」のアイコン・Version・Revision表示 |
| `HelloEWatch/WatchStore.swift` | 状態管理、専用キューでのDB・ファイル処理、iPhone通信 |
| `HelloEWatch/DAO.swift` / `SQLite3.swift` | 既存DBの読み出し、安全な取り込み、接続・ステートメント管理 |
| `HelloEWatch/Words.swift` / `JSONRW.swift` / `myCSV.swift` | HelloEWord互換モデルとファイル解析 |
| `EWatch Watch App/PhoneConnector.swift` | Watch通信、受信検証、直前の表示の保存 |
| 各ターゲットの `WatchSnapshot.swift` | 同一内容の通信モデル。変更時は両方を更新 |

アイコンはHelloEWordの赤い本を踏襲し、白文字で1行目「Watch」、2行目「EW」としています。iPhone・Watchの両AppIconに1024×1024画像を設定しています。

## ご自身でのビルド・動作確認

この修正を行ったエージェントはビルド、シミュレーター起動、実機確認、テスト実行を行っていません。ソース差分、通信モデルの一致、アイコン参照と画像サイズの整合性のみ確認しています。以下を手元で確認してください。

1. iPhone・Watchの両ターゲットをビルドし、両端末のアプリを更新する。
2. データなしの環境で起動し、取り込み案内が表示される。既存環境では以前の単語が残る。
3. HelloEWordの全項目JSON、従来8項目JSON、出題用JSON、16列CSVを取り込める。
4. カンマ・引用符・改行・日本語を含むCSVの意味が元の文章と一致する。
5. 複数の本から一部を選択して追記できる。キャンセルで既存件数が変わらない。
6. 全データ置き換えの確認をキャンセルすると既存件数が変わらず、実行すると選択した本だけになる。
7. 空ファイル、途中の不正数値、列不足、単語の空欄でエラーを表示し、既存データが残る。
8. 「対象」「検索」ボタンがなく、各Pickerに「すべて」がある。本・章・頁の選択変更だけで件数が更新される。
9. Watchの送信、左右スワイプによる前後移動、先頭・末尾、意味の表示切り替え、長文スクロール、前後移動用矢印が表示されないことを確認する。
10. 連打、iPhoneでの検索変更中のWatch操作、未接続・再接続、アプリの再起動で番号と単語が一致する。
11. 未接続時は直前の1件を保持する。失敗時だけ小さな「再同期」が表示され、未接続・通信中は無効、正常受信後は非表示になる。検索0件を同期すると古い単語が消える。
12. iPhone・Watch両方のホーム画面でアイコンとアプリ表示名「WatchEWord」を確認する。
13. 本を変更すると章・頁が「すべて」に戻り、その本の章だけを自然順で表示する（1、2、10など）。章を変更すると頁が「すべて」に戻り、その本・章の頁だけを数値順で表示する。
14. 「すべて」と空の本名・章名、頁0を区別して検索できる。引用符を含む本名や検索0件でもクラッシュせず、取り込み成功後は3項目とも「すべて」に戻る。
15. タイトル行右端の歯車からAboutを開き、WatchEWordのアイコン・Version・Revisionと「WatchEWordについて」が表示され、「閉じる」で戻れる。
