# HelloEWord

英単語を本・章・頁・通番ごとに整理して学習するiPhone用アプリです。SwiftUIで画面を構成し、学習データを端末内のSQLiteに保存します。

## 開発環境

- iOS 18.0以降を対象とするXcodeプロジェクトです。
- `HelloEWord.xcodeproj`をXcodeで開き、実行先と署名を設定してください。
- ビルド・動作確認は利用者が行う方針です。改修途中のソースでは一度ビルド成功を確認しましたが、その後の修正を含む最終ソースのビルド・動作確認は未実施です。

## 閲覧と検索

上部には現在レコード／検索結果の総件数と、頁／通番を青い丸囲みで表示します。本のメニューから閲覧する本を選択できます。`P.12/No.3`は12頁・通番3を表します。検索結果がない場合は0/0を表示します。

- 本を選ぶと、その本の単語を検索します。
- 章・頁・番号の入力値を変更すると、選択中の本と変更した項目を条件に自動検索します。
- 章・頁・番号を同時にAND検索する方式ではありません。変更した項目以外の入力欄は空になります。
- 入力欄を空にすると、その本全体を表示します。頁・番号は整数を使用し、不正な数値の入力途中には検索しません。
- 検索後は結果の先頭を表示します。番号はDBの主キーではなく、単語の通番です。
- 左へスワイプすると次、右へスワイプすると前の単語へ移動します。端では移動しません。
- スワイプや前後ボタンによる切り替えでは表示全体を横にスライドさせます。「視差効果を減らす」が有効な場合はフェードします。
- 下部には先頭・前・次・末尾への移動ボタンがあります。
- 長い語釈や例文は縦にスクロールできます。閲覧画面の本文は表示専用で、文字の選択・コピーができます。

単語と品詞の下に、意味・語釈・類似語・反意語・関連語・英文・和文・備考を表示します。各項目名は青色で、左の小さな丸ボタンで表示を切り替えます。青いチェック付きの丸は表示中、丸枠は非表示です。

起動時は意味・英文・和文の3項目だけを選択状態にします。連続する非表示項目は横に並べ、画面幅に合わせて折り返します。選択状態は閲覧中の単語を切り替えても維持しますが、永続保存はしていません。

品詞の右には①などの連番を表示します。連番0の横棒は表示しません。

## 登録・編集・削除

右下の歯車メニューから操作します。

| メニュー | 内容 |
| --- | --- |
| New | 別画面で単語を新規登録します。初期の本は選択中の本です。 |
| Edit | 現在の単語を別画面で編集します。 |
| Del | 確認後に現在の単語を削除します。 |
| エクスポート | JSONまたはCSVでデータを保存します。 |
| インポート | JSONまたはCSVから、本を選択して取り込みます。 |
| 出題用JSON | 選択中の本と頁範囲から出題用データを保存します。 |
| 初期化 | 確認後に、すべての本・単語を削除します。 |

編集画面では本・章・頁・通番・連番・単語・品詞・意味・語釈・類似語・反意語・関連語・英文・和文・備考を編集できます。連番は0＝横棒、1＝①、2＝②…として保存します。

保存前に数値と単語の入力を検証します。保存に失敗した場合は入力を残してエラーを表示します。キャンセルでは保存しません。保存後は保存した単語を表示し、削除後は有効な位置に調整します。

初期化は取り消せません。必要な学習データは事前に「全」を対象にエクスポートしてください。初期化後はNewから手入力で登録できます。書き出したファイルは削除しません。

## エクスポート

1. 歯車メニューから「エクスポート」を選びます。
2. JSONまたはCSVを選びます。
3. 対象を「全／本／章／頁／番／単」から選びます。
4. 「全」以外は、ダイアログを開いた時点で選択中の本を対象にします。章・頁・番・単では条件を入力します。「単」は単語の完全一致です。
5. 「次へ」で保存先を選びます。

JSON・CSVとも全項目を出力します。出力操作によって閲覧中の検索結果は変更しません。初期ファイル名は`EWordData.json`または`EWordData.csv`です。

## インポート

1. 歯車メニューから「インポート」を選びます。
2. JSONまたはCSVを選び、「次へ」でファイルを選びます。
3. 全レコードの検証後、本の名前と件数を一覧表示します。取り込む本を選びます（複数選択可）。
4. 選択した件数を確認し、「追記」または「全データを置き換え」を選びます。

「追記」は既存データを残して追加します。同じデータも追加されるため、繰り返し取り込むと重複します。「全データを置き換え」は選択していない本も含む既存の全単語を削除し、ファイルから選択した本だけを保存します。キャンセルではDBを変更しません。

空ファイル、不正な列数・数値、単語の空欄などは取り込みません。DBへの反映はトランザクション内で行い、途中で失敗した場合はロールバックします。入力ファイルのIDは主キーとして再利用せず、端末側で新しいIDを採番します。

### CSV形式

従来と同じUTF-8の16列を使用します。

```csv
ID,連番,単語,品詞,意味,語釈,類似語,反意語,関連語,英文,和文,備考,本,章,頁,通番
```

連番・頁・通番は整数です。章は文字列として扱います。出力は各フィールドを引用符で囲み、フィールド内の引用符を二重にエスケープします。カンマ・引用符・改行を含む文章、UTF-8のBOM、CRLF改行に対応する処理を実装しています。

### JSON形式

全項目JSONは次の形式の配列です。

```json
[
  {
    "id": 1,
    "seq": 0,
    "word": "enhance",
    "type": "verb",
    "mean": "高める",
    "expr": "",
    "simlr": "",
    "invrt": "",
    "relat": "",
    "eibun": "Salt can enhance the flavor of many dishes.",
    "wabun": "塩は料理の風味を高めることができる。",
    "descr": "",
    "book": "上級英英単",
    "stage": "1",
    "page": 12,
    "numb": 3
  }
]
```

従来の8項目JSON（book・stage・page・numb・word・mean・eibun・wabun）も読み込めます。省略された品詞・語釈・類似語・反意語・関連語・備考は空文字、連番は0として取り込みます。従来のJSONに含まれていなかった情報は復元できません。

## 出題用JSON

「出題用JSON」では、選択中の本の開始頁から2頁先までを対象にします。ランダム順のオン・オフを選択でき、ファイル名の初期値は`EWordQuestions.json`です。

従来と同じ8項目だけを出力します。完全なバックアップには、通常のエクスポートで「全」を選んでください。

## ソース構成とデータ保存

| ファイル | 内容 |
| --- | --- |
| `HelloEWord/HelloEWordApp.swift` | アプリの起動 |
| `HelloEWord/ContentView.swift` | 閲覧・検索・編集・入出力画面、丸ボタン、非表示項目の折り返し配置 |
| `HelloEWord/DAO.swift` | 単語モデル、入力検証、DB検索・更新・取り込み |
| `HelloEWord/SQLite3.swift` | SQLite接続、SQL実行、トランザクション、リソース管理 |
| `HelloEWord/myCSV.swift` | 16列CSVの生成・解析 |
| `HelloEWord/JSONRW.swift` | 全項目JSONと出題用JSONの生成・読み込み |
| `HelloEWord/SmpFileDocument.swift` | ファイル書き出し用ドキュメント |

DBはアプリのDocuments内の`eword_sqlite3`、テーブルは`eword`です。既存のDB名・テーブル名・列構成を維持しています。起動時にテーブルがなければ作成します。

ソースのGitバックアップには、端末内の学習データは含まれません。学習データはエクスポートで保存してください。
