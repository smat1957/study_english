# EWord

アプリの表示名・閲覧画面のタイトル・About画面の名前は「EWord」です。

英単語を本・章・頁・通番ごとに整理して学習するiPhone用アプリです。SwiftUIで画面を構成し、学習データを端末内のSQLiteに保存します。

## 開発環境

- iOS 18.0以降を対象とするXcodeプロジェクトです。
- `HelloEWord.xcodeproj`をXcodeで開き、実行先と署名を設定してください。
- ビルド・動作確認は利用者が行う方針です。改修途中のソースでは一度ビルド成功を確認しましたが、その後の修正を含む最終ソースのビルド・動作確認は未実施です。

## 閲覧と検索

タイトル下の2行目では、現在レコード／検索結果の総件数と頁／通番をfootnoteサイズ・薄青の丸囲みで左に並べます。2行目・3行目の文字はライトモードで黒、ダークモードで白です。本の選択は残りの幅を使って右寄せに表示します。本の名前は3行目の選択値と同じsubheadlineサイズです。本のメニューから閲覧する本を選択できます。`P.12/No.3`は12頁・通番3を表します。検索結果がない場合は0/0を表示します。

- 本を選ぶと、その本の単語を検索します。
- 章・頁・番号は入力欄ではなく、DBに存在する値を選ぶメニューです。3行目の項目名はfootnoteサイズで、選択値の文字サイズは従来のままです。
- 章は選択中の本、頁は選択中の本・章、番号は選択中の本・章・頁から候補を取得します。
- 章は「2→10」の順になる自然順、頁・番号は数値の昇順で表示します。章が空のデータは「（章なし）」として選択できます。
- 選択を変更すると、選択済みの本・章・頁・番号を組み合わせて自動検索し、結果の先頭を表示します。
- 本を変更すると章・頁・番号、章を変更すると頁・番号、頁を変更すると番号をリセットします。
- 各メニューの「すべて」で、その階層以下の絞り込みを解除できます。章未選択では頁・番号、頁未選択では番号を選べません。
- 番号はDBの主キーではなく、単語の通番です。保存・削除・取り込み後は候補を読み直し、存在しなくなった選択を解除します。
- 左へスワイプすると次、右へスワイプすると前の単語へ移動します。端では移動しません。
- スワイプや前後ボタンによる切り替えでは表示全体を横にスライドさせます。「視差効果を減らす」が有効な場合はフェードします。
- 下部には先頭・前・次・末尾への移動ボタンがあります。「前」と「次」の間には、上部と同じ現在位置／検索結果の総件数をfootnoteサイズ・標準の文字色（ライトモードでは黒、ダークモードでは白）で表示します。0件なら0/0を表示します。矢印のサイズは維持しています。
- 長い語釈や例文は縦にスクロールできます。閲覧画面の本文は表示専用で、文字の選択・コピーができます。

単語と品詞の下に、意味・語釈・類似語・反意語・関連語・英文・和文・備考を表示します。各項目名は青色で、左の小さな丸ボタンで表示を切り替えます。青いチェック付きの丸は表示中、丸枠は非表示です。

初回起動時は意味・英文・和文の3項目だけを選択状態にします。非表示項目は本文の最下部にまとめ、横に並べて画面幅に合わせて折り返します。選択すると本来の項目順に戻って本文を表示します。選択状態は閲覧中の単語を切り替えても維持し、次回起動時にも復元します。

品詞の右には①などの連番を表示します。連番0の横棒は表示しません。

## 最後の閲覧状態の復元

選択中の本・章・頁・番号、最後に表示していた単語のID、各項目の表示／非表示を端末内のUserDefaultsに保存します。選択変更・単語移動・保存・削除・取り込み後と、バックグラウンド移行時に保存します。

次回起動時はDBから検索し直して、同じ単語をIDで探して表示します。存在しなくなった検索条件は上位から解除し、単語が削除されている場合は検索結果の先頭、本がなくなっている場合は利用可能な本を表示します。保存情報がない場合や読み込めない場合は通常の初期表示を使用します。

初期化では保存済みの本・検索条件・単語IDもリセットします。各項目の表示／非表示は維持します。未保存の編集内容、開いていたダイアログ、スクロール位置は復元対象ではありません。

## 登録・編集・削除

右下の歯車メニューから操作します。

| メニュー | 内容 |
| --- | --- |
| 新規 | 別画面で単語を新規登録します。初期の本は選択中の本です。 |
| 編集 | 現在の単語を別画面で編集します。 |
| 出題用JSON | 選択中の本と頁範囲から出題用データを保存します。 |
| エクスポート | JSONまたはCSVでデータを保存します。 |
| インポート | JSONまたはCSVから、本を選択して取り込みます。 |
| 初期化 | 確認後に、すべての本・単語を削除します。 |
| About | 「EWordについて」を表示します。 |

メニューは表の上から下の順序に固定しています。単語の削除は集合メニューではなく編集画面から行います。新規・編集の後、インポートの後、初期化の後に区切りを設けています。AboutにはEWアイコン・Version・Revisionと「閉じる」を表示します。VersionとRevisionは実行中のアプリのBundle情報から取得します。

編集画面では本・章・頁・通番・連番・単語・品詞・意味・語釈・類似語・反意語・関連語・英文・和文・備考を編集できます。すべてのデータにグレイの固定の項目名を表示し、入力後も項目名が見えます。掲載位置の本・章・頁・通番・連番は、それぞれ項目名と入力値を横に並べた1行で表示します。連番の項目名は「連番」のみです。連番は0＝横棒、1＝①、2＝②…として保存します。

既存単語の編集画面では、「キャンセル」のすぐ右に赤文字の「削除」を表示します。それぞれ独立したボタンで、iOS 26以降では枠を分けて表示します。編集画面のタイトルは「編集」です。確認後、現在編集中の単語を削除して閲覧画面へ戻ります。未保存の変更は保存しません。削除に失敗した場合は編集画面と入力内容を残してエラーを表示します。新規登録画面には削除ボタンを表示しません。

編集画面では、左へスワイプすると次、右へスワイプすると前の記事へ直接移動できます。移動順は編集を開いた時点の検索結果の順序を保持します。本・章・頁・通番などを編集しても、編集中の移動順は変わりません。変更がある場合は数値と単語を検証して自動保存してから移動し、変更がない場合は保存せず移動します。入力不備やDB保存の失敗時は移動せず、入力を残してエラーを表示します。縦スクロールと区別し、横方向の移動が縦方向より大きく、60ポイント以上のスワイプで切り替えます。

検索結果の先頭から前へは移動しません。最後の記事から次へ進むと、その記事の本を初期値にした新規登録画面になります。新規入力が未変更なら、右スワイプで登録せず最後の記事へ戻れます。入力を変更した場合は検証・保存してから前の記事へ戻ります。新規入力を保存してさらに次へ進むと、続けて新規登録できます。未変更の新規入力から次へは移動しません。歯車メニューの「新規」から開いた場合は検索結果との前後移動を行わず、登録後に次の新規入力へ進めます。

スワイプによる自動保存では閲覧中の検索条件の解除を行いません。ただし保存後の候補再取得で存在しなくなった条件は従来どおり解除されます。編集中の移動順は保持します。「保存」は保存して閲覧画面へ戻り、保存した単語の本を表示して絞り込みを解除します。「キャンセル」は現在の記事の未保存分だけを破棄します。スワイプで自動保存済みの記事は取り消しません。削除はスワイプ後も現在編集中の記事を対象にします。

保存前に数値と単語の入力を検証します。保存に失敗した場合は入力を残してエラーを表示します。キャンセルでは保存しません。保存後は保存した単語を表示し、削除後は有効な位置に調整します。

初期化は取り消せません。必要な学習データは事前に「全」を対象にエクスポートしてください。初期化後は「新規」から手入力で登録できます。書き出したファイルは削除しません。

## エクスポート

1. 歯車メニューから「エクスポート」を選びます。
2. JSONまたはCSVを選びます。
3. 対象を「全／本／章／頁／番／単」から選びます。
4. 「全」以外は、ダイアログを開いた時点で選択中の本を対象にします。章・頁・番・単では条件を入力します。「単」は単語の完全一致です。
5. 「次へ」で保存先を選びます。

JSON・CSVとも全項目を出力します。出力操作によって閲覧中の検索結果は変更しません。初期ファイル名は`EWordData.json`または`EWordData.csv`です。

## インポート

1. 歯車メニューから「インポート」を選びます。
2. JSONまたはCSVを選び、「次へ」でファイルを選びます。
3. 全レコードの検証後、本の名前と件数を一覧表示します。取り込む本を選びます（複数選択可）。
4. 選択した件数を確認し、「追記」または「全データを置き換え」を選びます。

「追記」は既存データを残して追加します。同じデータも追加されるため、繰り返し取り込むと重複します。「全データを置き換え」は選択していない本も含む既存の全単語を削除し、ファイルから選択した本だけを保存します。キャンセルではDBを変更しません。

空ファイル、不正な列数・数値、単語の空欄などは取り込みません。DBへの反映はトランザクション内で行い、途中で失敗した場合はロールバックします。入力ファイルのIDは主キーとして再利用せず、端末側で新しいIDを採番します。

### CSV形式

従来と同じUTF-8の16列を使用します。

```csv
ID,連番,単語,品詞,意味,語釈,類似語,反意語,関連語,英文,和文,備考,本,章,頁,通番
```

連番・頁・通番は整数です。章は文字列として扱います。出力は各フィールドを引用符で囲み、フィールド内の引用符を二重にエスケープします。カンマ・引用符・改行を含む文章、UTF-8のBOM、CRLF改行に対応する処理を実装しています。

### JSON形式

全項目JSONは次の形式の配列です。

```json
[
  {
    "id": 1,
    "seq": 0,
    "word": "enhance",
    "type": "verb",
    "mean": "高める",
    "expr": "",
    "simlr": "",
    "invrt": "",
    "relat": "",
    "eibun": "Salt can enhance the flavor of many dishes.",
    "wabun": "塩は料理の風味を高めることができる。",
    "descr": "",
    "book": "上級英英単",
    "stage": "1",
    "page": 12,
    "numb": 3
  }
]
```

従来の8項目JSON（book・stage・page・numb・word・mean・eibun・wabun）も読み込めます。省略された品詞・語釈・類似語・反意語・関連語・備考は空文字、連番は0として取り込みます。従来のJSONに含まれていなかった情報は復元できません。

## 出題用JSON

「出題用JSON」では、選択中の本の開始頁から2頁先までを対象にします。ランダム順のオン・オフを選択でき、ファイル名の初期値は`EWordQuestions.json`です。

従来と同じ8項目だけを出力します。完全なバックアップには、通常のエクスポートで「全」を選んでください。

## ソース構成とデータ保存

| ファイル | 内容 |
| --- | --- |
| `HelloEWord/HelloEWordApp.swift` | アプリの起動 |
| `HelloEWord/ContentView.swift` | 閲覧・検索・編集・入出力画面、表示切り替え、折り返し配置、閲覧状態の保存・復元 |
| `HelloEWord/DAO.swift` | 単語モデル、入力検証、階層選択の候補取得、複合条件検索、更新・取り込み |
| `HelloEWord/AboutView.swift` | EWアイコンとVersion・Revisionを表示するAbout画面 |
| `HelloEWord/SQLite3.swift` | SQLite接続、SQL実行、トランザクション、リソース管理 |
| `HelloEWord/myCSV.swift` | 16列CSVの生成・解析 |
| `HelloEWord/JSONRW.swift` | 全項目JSONと出題用JSONの生成・読み込み |
| `HelloEWord/SmpFileDocument.swift` | ファイル書き出し用ドキュメント |

DBはアプリのDocuments内の`eword_sqlite3`、テーブルは`eword`です。既存のDB名・テーブル名・列構成を維持しています。起動時にテーブルがなければ作成します。

ソースのGitバックアップには、端末内の学習データは含まれません。学習データはエクスポートで保存してください。

## アプリアイコン

HelloECompoと同じ明るい赤の本のデザインを使用し、白い文字を「EW」にしています。通常表示とダーク表示に同じ画像を設定しています。

- 登録画像：`HelloEWord/Assets.xcassets/AppIcon.appiconset/EW-AppIcon-1024.png`（1024×1024、透明背景なし）
- About表示用画像：`HelloEWord/Assets.xcassets/AboutAppIcon.imageset/EW-AppIcon-1024.png`
- 組み込み画像生成ツールで、HelloECompoのアイコンを参照して「色・本の形・白背景を維持し、ECだけをEWに変更する」指示で作成しました。
