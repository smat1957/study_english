# ECompo

英文・和文を本、分野、話題、題目ごとに整理して学習するiPhone用アプリです。SwiftUIで画面を構成し、データを端末内のSQLiteに保存します。

ホーム画面のアプリ表示名、閲覧画面のタイトルヘッダ、About画面のアプリ名は「ECompo」です。

## 開発環境

- iOS 18.0以降を対象とするXcodeプロジェクトです。
- `HelloECompo.xcodeproj`をXcodeで開き、実行先のiPhoneまたはシミュレータを選択します。
- 実機で実行する場合は、XcodeのSigning & Capabilitiesで署名を設定してください。
- このREADMEに記載した改修について、ビルド・実機・シミュレータでの動作確認は未実施です。確認は利用者が行う方針です。

## 閲覧と検索

最上段の高さ28ptのタイトル行にアプリ名「ECompo」を中央表示します。その下のバーに現在のレコード位置／検索結果の件数、掲載位置、本の選択を表示します。`P.30/L.1`は30頁・1行を表します。閲覧画面の頁・行は表示専用です。

件数と頁・行は左側に必要な幅で並べ、残りの幅を右寄せの本の選択に使用します。

- 本を選ぶと、その本の記事を検索します。
- 分野の候補は選択中の本に含まれるものだけ、話題はその本と分野に含まれるものだけ、題目はその本・分野・話題に含まれるものだけを表示します。
- 分野・話題・題目の候補は、それぞれ上記の範囲内で候補ごとの最小ページ番号の昇順に表示します。同じ最小ページ番号の場合は名称順に表示します。本の候補は名称順です。
- 分野を変更すると本＋分野、話題を変更すると本＋分野＋話題、題目を変更すると本＋分野＋話題＋題目のAND条件で自動検索します。上位を変更した際、下位は検索結果の先頭記事に合う選択へ更新します。
- 検索後は結果の先頭を表示します。検索ボタンや検索対象を選ぶ欄はありません。
- 検索・記事移動のたびに検索条件と記事ID・表示位置を端末に保存し、再起動時に検索結果と位置を復元します。記事がなくなった場合は範囲内の位置へ、条件に該当する記事がなくなった場合は全件表示へ戻ります。初期化すると保存した閲覧状態も空の状態へ更新します。
- 左へスワイプすると次、右へスワイプすると前の記事へ移動します。端では移動しません。
- 文章領域の下端にはHelloEWordと同じアイコン・並びの「最初・前・次・最後」の移動ボタンを、高さ28ptの行に背景・枠なしで重ねて表示します。背後の文章は透けて見えます。先頭・末尾では該当するボタンを、記事がない場合はすべての移動ボタンを無効にします。
- 記事の切り替えには横方向のアニメーションを使用します。「視差効果を減らす」が有効な場合はフェードに切り替えます。
- 長い文章は縦にスクロールできます。
- 初期状態は和文だけOn、英文・備考はOffです。初期化後も同じ状態に戻ります。各スイッチで表示／非表示を切り替えます。
- 閲覧画面の文章に触れても編集用キーボードは開きません。

## 新規登録・編集・削除

右下の浮動する歯車メニューから新規登録・編集などを操作します。「新規・編集」「エクスポート・インポート」「初期化」「About」の各グループの間に区切り線を表示します。記事の削除は編集画面から操作します。

| メニュー | 操作 |
| --- | --- |
| 新規 | 別画面で新規登録します。本・分野・話題・題目は現在の選択、章・頁は現在の記事の値を初期入力します。行は0、文章・備考は空欄から始めます。 |
| 編集 | 現在の記事を別画面で編集します。 |
| エクスポート | 形式と検索対象を選び、ファイルを保存します。 |
| インポート | 形式とファイルを選び、データを取り込みます。 |
| 初期化 | 入出力項目の下の区切りに表示。確認後、アプリ内のすべての本・記事を削除します。 |
| About | 「ECompoについて」画面でアプリアイコン、アプリ名、Version、Revisionを表示します。「閉じる」で閲覧画面へ戻ります。 |

About画面のVersionはアプリの`CFBundleShortVersionString`、Revisionはビルド番号の`CFBundleVersion`から取得します。現在のプロジェクト設定はVersion 1.0、Revision 1です。

編集画面では、本・行・頁・章・分野・話題・題目・和文・英文・ヒント・その他の備考を編集できます。保存前に数値や内容を検証し、保存できない場合は入力を残してエラーを表示します。キャンセルでは編集内容を保存しません。

編集画面の「キャンセル」と赤文字の「削除」は、それぞれ独立した枠で表示します。確認後、編集中の記事を削除して閲覧画面に戻り、検索結果・件数・表示位置を更新します。未保存の編集内容は保存しません。削除に失敗した場合は編集画面を開いたままエラーを表示します。新規登録画面には「削除」を表示しません。

## データの初期化と手入力での開始

歯車メニューの「初期化」を選び、確認画面の「すべて削除して初期化」を押すと、DB内の記事をすべて削除します。表示件数は0/0となり、本・分類の選択肢と文章表示を空にします。削除に失敗した場合はエラーを表示します。書き出したJSON・CSVファイルは削除しません。

初期化後は歯車メニューの「新規」で編集画面を開き、本の名前や英文・和文などを手入力して保存できます。最初の記事の保存後、本と分類の選択肢も更新されます。初期化は取り消せないため、必要なデータはあらかじめエクスポートしてください。

## エクスポート

1. 歯車メニューから「エクスポート」を選択します。
2. ダイアログのラジオボタンでJSONまたはCSVを選びます。
3. 検索対象を「全／本／分野／話題／題目／頁」から選びます。
4. 「次へ」で保存先を選択します。

「全」はすべての本を対象とします。それ以外は、ダイアログを開いた時点で閲覧画面に選択・表示されている本、分類、頁を検索条件に使用します。ダイアログに対象の条件を表示します。JSON・CSVともに検索結果をすべて出力し、出力操作で閲覧中の記事や検索結果を変更しません。

ファイル名の初期値は`ECompoData.json`または`ECompoData.csv`です。

## インポート

1. 歯車メニューから「インポート」を選択します。
2. ラジオボタンでJSONまたはCSVを選びます。
3. 「次へ」でファイルを選択します。
4. 全レコードの検証後、ファイルに含まれる本の名前と件数を一覧表示します。取り込む本を選択します（複数選択可）。
5. 選択した本の取り込み件数を確認し「追記」または「置き換え」を選びます。
6. 取り込み後は本の選択肢をDBから読み直し、取り込んだ本の記事を表示します。「置き換え」では取り込んだ本だけが選択肢になり、「追記」では既存の本も残ります。

「追記」は既存データを残して追加します。同一内容を再度取り込むと重複するため、同じファイルの繰り返し取り込みに注意してください。「置き換え」はDB内の既存の記事をすべて削除し、ファイルで選択した本のデータだけを保存します。既存の本は残りません。処理をキャンセルした場合はデータを変更しません。

読み込み・検証に失敗したファイルや、データのないファイルは取り込みません。DBへの反映はトランザクション内で行い、途中で失敗した場合はロールバックします。ファイル内のIDは取り込み先の主キーとして再利用せず、端末側で新しいIDを採番します。

### CSV形式

UTF-8の12列を次の順で使用します。

```csv
ID,英文,和文,ヒント,行,頁,章,題目,主題,分野,本,備考
```

「主題」は画面の「話題」に対応します。「行」「頁」「章」には整数が必要です。文字列内のカンマ・改行・引用符を扱うため、出力時はフィールドを引用符で囲み、引用符自体は二重にエスケープします。UTF-8のBOM付きファイルやCRLF改行にも対応する処理を実装しています。

### JSON形式

レコードを並べた配列を使用します。

```json
[
  {
    "id": 1,
    "eibun": "English sentence.",
    "wabun": "日本語の文。",
    "hint": "ヒント",
    "line": 1,
    "page": 30,
    "chap": 1,
    "title": "題目",
    "topic": "話題",
    "field": "分野",
    "book": "本の名前",
    "description": "その他の備考"
  }
]
```

以前の8項目（`book`、`field`、`topic`、`title`、`page`、`line`、`wabun`、`eibun`）だけのJSONも読み込めます。省略された`hint`と`description`は空文字、`chap`は0として取り込みます。

## ソース構成

| ファイル | 内容 |
| --- | --- |
| `HelloECompo/HelloECompoApp.swift` | アプリの起動 |
| `HelloECompo/ContentView.swift` | 閲覧、検索、編集画面、浮動メニュー、入出力ダイアログ |
| `HelloECompo/AboutView.swift` | アプリアイコン、Version、Revisionを表示するAbout画面 |
| `HelloECompo/DAO.swift` | レコードの検証、SQLiteの検索・更新・取り込み |
| `HelloECompo/SQLite3.swift` | SQLite接続、パラメータ設定、SQL実行、トランザクション |
| `HelloECompo/CSV.swift` | CSVの生成・解析 |
| `HelloECompo/JSONRW.swift` | JSONの生成・読み込み |
| `HelloECompo/SmpFileDocument.swift` | ファイル書き出し用のドキュメント |

データベースはアプリのDocuments内の`ecompo_sqlite3`に保存します。起動時に必要なテーブルを作成します。ソースのGitバックアップと端末内の学習データは別のものです。学習データの保存には「全」を対象にエクスポートしてください。
